# Release Gates

Production promotion requires evidence for applicable gates:

- Lint and static analysis
- Unit tests
- Integration tests
- End-to-end tests
- Policy tests
- Tenant isolation tests
- RAG evaluation
- Agent evaluation
- Prompt regression
- Security scanning
- Dependency and secret scanning
- Container scanning
- Agent red-team tests
- Accessibility tests
- Performance and resilience tests
- Backup restore evidence
- DR exercise evidence when required
- Evidence bundle generation
- Release approval
- Canary deployment
- Post-deployment verification

A critical failed gate blocks certification.
